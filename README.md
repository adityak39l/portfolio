## 🌟 Overview

This is the official personal portfolio website of **Aditya Kumar Verma**, Fourth-year B.Tech (Electronics & Instrumentation Engineering) student at **Bundelkhand University (IET), Jhansi** (SGPA: 8.0/10).

The design synthesizes the best elements from two distinct aesthetic paradigms:
1. **Editorial Neo-Brutalism (Paper Theme)**: Warm paper tones, crisp ink borders, hard offset print-shadows, handwritten marker highlights, washi tape accents, and interactive sketch doodle tools.
2. **Cosmic Cyber Tech (Space Theme)**: Deep space obsidian canvas with glowing cyan highlights, interactive particle constellation physics, and glassmorphic elements.

---

## ✨ Key Features

- **🌓 Dual-Theme Engine**: Seamless toggle between **Paper Editorial** and **Cosmic Space** modes with persistent `localStorage` memory.
- **✎ Interactive Doodle Pen Tool**: Visitors can sketch, draw, sign, or leave notes directly on the webpage with multi-color ink pickers and clear canvas functionality.
- **🔊 Web Audio SFX Synthesizer**: Built-in mechanical click and stamp audio feedback synthesized natively with the Web Audio API (100% offline, zero external audio assets).
- **🌌 Interactive Canvas Constellation Engine**: Fullscreen particle network responding to cursor movement.
- **⌨️ Dynamic Terminal Typewriter**: Cycling through credentials and engineering specializations.
- **📁 Shipped Projects Showcase with Live Links**:

  - [Top Engineering Colleges Finder](https://college2.ccbp.tech/) — Multi-criteria instant search filter.
  - [Birthday Wish Generator](https://wishcardbirth.ccbp.tech/) — Dynamic DOM greeting engine.
  - [WanderLust Booking Hub](https://github.com/adityak39l) — Full-stack MERN rental application.

## 🚀 Getting Started

No build tools or bundlers are required!

1. Clone the repository:
   ```bash
   git clone https://github.com/adityak39l/Aditya-Portfolio39.git
   ```
2. Open `index.html` in any modern web browser:
   - Double-click `index.html`, OR
   - Run with VS Code Live Server: Right-click `index.html` -> *Open with Live Server*.
